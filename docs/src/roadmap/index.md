# Roadmap

DLSlime roadmaps are organized by delivery window:

- [2026-09 to 2026-11 — Declarative Distributed I/O Runtime](2026_09-2026_11.md)
- [2025 Q3 — Transport Foundations](2025_Q3.md)

The 2025 Q3 roadmap records the transport-engine foundation. The current
September-to-November 2026 roadmap defines DLSlime as the declarative
distributed I/O runtime for DLEngine and other inference services: logical
Memory, unified Operation/Future semantics, an Agent-owned resource and path
model, and explicit reuse boundaries for UCX, NIXL, Mooncake, NCCL, and native
backends.
